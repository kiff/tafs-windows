### English
**tafs for Windows v1.2.1 (beta)**

**This beta isn't signed yet. Windows may say it's from an unknown publisher: choose More info, then Run anyway. A signed version follows.**

**What it does:** tafs on your Windows PC: your tafs, what needs you, Coach and the Record, laid out as on the iPad. Once you've added this PC from your phone, you can approve on it with Windows Hello.

**In this release**
- Big screens: every page is one centred column, so nothing sits against the left with half the window empty, and Plan & usage and Calendar no longer run past the window's edge.
- Connect apps: an app to sign in to again shows "Sign in again" in full, with its button under it.
- Account: each explanation sits next to what it explains: Chrome's under the Chrome row, the emailed code's warning in Sign-in, and How tafs works is one section.
- Overview: who uses a taf goes onto a second line instead of being cut.
- Allow this from now on: this PC approves a change to a Card only if it can read every term in it. A term it doesn't know is never approved unseen.

**What it needs:** Windows 10 (version 1809 or later) or Windows 11, with a TPM, Windows Hello to approve, and the phone you use with tafs, to add this PC.

**Install:** Run the setup for your PC: `x64` for most PCs, `arm64` for ARM ones. It replaces v1.2.0 and removes its folder. It asks for administrator rights once, then offers Open tafs.

**Check the file:** In PowerShell, in the folder with the setup: `Get-FileHash .\<setup file>`. The hash must match the SHA-256 below; if it doesn't, delete the file and don't run it.
