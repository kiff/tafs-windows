# The port checklist

Each iPad view file (kiff/tafs `ios/Tafs/Views`, at d14217f) against its Windows status. A file is **ported** when
every branch it draws is on Windows, **partial** when part of it is (what's missing is named), **not started**, or
**not for Windows** (and why). The tables describe main; what an open pull request brings is marked with its number,
"(#65, open)". The PR that ports a file updates its line here. The list is anchored at d14217f, behind the pin: six view
files have grown since (CalendarView, ConnectAppsView, HomeSplitView, RecordView, SetupChatView, TafDetailView), and
their lines here are d14217f's.
